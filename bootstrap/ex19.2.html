Exercise 19.2 - Customize Bootstrap with Sass

Create scss/custom.scss:

// Override variables BEFORE importing Bootstrap
$primary: #ff5733;
$border-radius: 0.5rem;

@import "../node_modules/bootstrap/scss/bootstrap";

Compile: npm run sass

Now use the compiled dist/custom.css in your HTML to see the overridden $primary and $border-radius.

This text uses the overridden $primary color (#ff5733) after compiling.
